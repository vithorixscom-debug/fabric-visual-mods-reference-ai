# What is in this tree

Two Fabric rendering mods, `1.21.x` and `26.x`, plus notes. `VisualPrimer/` is a second Gradle build of the same pictures, with its own packages and default colors, under the same MIT license (`VisualPrimer/LICENSE`). The license is MIT, Copyright (c) 2026 VixoTeam Systems.

The contracts name the methods that compiled. A sentence that disagrees with `1.21.x/CONTRACT.md` or `26.x/CONTRACT.md` is stale. `CRAFT.md` is how a module is added. `1.21.x/PATTERNS.md` is what this mod draws. `OPTIMIZATION.md` is the optimizer notes. `MISTAKES.md` is symptom, cause, and fix for the failures this tree hit.

Third-party mod jars and their sources are not in this tree. See `THIRD_PARTY.md`.

There is no score sheet in this file.
